# 日历拼图

本地生产预览为 [游戏大厅](http://127.0.0.1:4287/) 和 [日历拼图](http://127.0.0.1:4287/calendar-puzzle/)。游戏入口 `/calendar-puzzle` 会沿用大厅站点的规则，跳转到带尾斜杠的路径。

## 棋盘与拼图

棋盘依据两张实物照片标注，坐标从左上角 `(0,0)` 开始，向右、向下递增。照片标注板宽 125 mm。网页依照需求使用中文标签、标题和底部文字。厚度和倒角按格宽比例设置。木纹为本地生成纹理，摩擦声和落木声为合成效果。视觉使用固定俯视、Canvas 木纹轮廓和 CSS 光影。

正式游戏采用已确认的全日期方案，固定 11 块、共覆盖 47 格。每块的局部坐标和视觉比例见 [正式配置](../src/calendar-puzzle/geometry.json)。下图是各块初始方向，`#` 为占格、`.` 为缺口，`/` 分隔行。

[照片读图配置](calendar-puzzle-photo.json)和[照片摆法](calendar-puzzle-photo-solution.json)保留供核对。照片上的拼法只露出 6 月、20 日和星期日。按接缝读出的 11 块可解 1,464 个组合。周二和周六会在星期边缘留下不能用多格块覆盖的孤立单格，周四会留下 3 格直条缺口，总计 1,098 个组合无解。当天目标的结果来自该配置完整枚举所有旋转、翻面和摆法。

全日期版将照片摆法中的 `(1,1)`、`(1,2)`、`(2,2)` 三格从 C 划给 B。B 变为 8 格，C 变为单格。棋盘和其他块沿用读图坐标。用于交叉验证的[港科大十块版公开实现](https://github.com/joveryz/calender-puzzle-solver)采用另一副棋盘，也通过本项目求解器全量验证。

## 运行和验证

复用仓库锁定的 Bun 1.4.2、Rust 1.99.0、`wasm32-unknown-unknown` 和 wasm-pack 0.15.1。首次配置参见[仓库运行说明](../README.md#local-setup)。

```sh
bun install --frozen-lockfile
bun run dev
bun run build
bun run preview --host 127.0.0.1 --port 4287
```

| 命令 | 用途 |
| --- | --- |
| `bun run build:wasm:calendar` | 从 `rust/calendar-puzzle` 单独生成 `src/generated/calendar-puzzle/calendar_puzzle.js`、类型声明和 `calendar_puzzle_bg.wasm` |
| `bun run test:rust:calendar` | 验证规则、变换、占格、存档、求解器与所有正式日期组合 |
| `bun run test:calendar:session` | 验证日期、计时、历史和成就 |
| `bun run verify:calendar --report src/calendar-puzzle/solvability.json` | 按公历 400 年循环去重，复查全部 2,562 个日期组合，重新生成可解性数据 |
| `bun run verify:calendar --date 2026-11-17` | 开发者获取指定日的一个经规则引擎复核的解 |
| `bun run verify:calendar docs/calendar-puzzle-photo.json --date 2026-11-17` | 复查原照片配置的周二，预期返回无解并以状态码 1 退出 |

布局和解包含闰日。正式配置查得 **2,562 个可解、0 个无解、0 个超时**。原生验证器用精确覆盖搜索，候选形状先枚举旋转和镜像、去掉几何重复，然后由独立的游戏规则重新放置和检查找到的解。求解器不在浏览器包里。页面加载只初始化游戏引擎。Vite 将生产 WASM 输出为 `dist/assets/calendar_puzzle_bg-*.wasm`。

### 本地验收

1. 打开大厅，旋转球形菜单到「日历拼图」。检查封面、说明、卡片和圆形箭头，进入游戏。
2. 打开「选择日期」，选择 2024-02-29，核对星期四。取消并确认当前目标仍在，再应用日期，确认回到待开始。
3. 用默认日期开始计时。拖块到有效格，再拖到缺口；后者回到图库。试试轻点旋转、长按翻转、按钮操作；拖动时按 Esc，检查原位置和步数。
4. 按 Tab 聚焦一块，用 R、F、方向键和 Enter 操作。打开「设置」和「规则」，关闭后点「继续挑战」。刷新后核对原位置和步数；音量、静音、配色留在本机。
5. 「全部收回」保留步数和用时。「重置关卡」创建同目标的新局并清空统计。
6. [2026-11-17 的验收解](../tests/calendar-all-dates-solution.json)可用于复现通关。放完 11 块应只露出 11 月、17 日、星期二。检查「成绩」里的本机最快记录，轻松模式通关只进入历史和成就。
7. 返回大厅，直接打开并刷新 `/calendar-puzzle`。窄屏可以从下方图库拖到棋盘，将指针移到屏幕上边缘能自动滚动。

现有 `vercel.json` 已加入此入口的路径映射。远端沿用 `scripts/build-vercel.sh`，按锁定工具链从源码生成 WASM。发布前需要确认本地验收。正式目标地址为 [game.grace-spring.top/calendar-puzzle](https://game.grace-spring.top/calendar-puzzle)。
